# Плавно — обновления

Личное приложение для практики английского на Android 8 и новее.

[Скачать Плавно 0.3.1](https://raw.githubusercontent.com/Nikita15313/plavno-updates/main/plavno-0.3.1.apk)

Установите APK поверх прежней версии, не удаляя приложение. Начиная с 0.3.0: **Настройки → Обновить приложение → Проверить и обновить**. Android попросит подтвердить установку. Учебная история и настройки сохраняются; переход 0.2→0.3 проверен на эмуляторе через интернет и системный установщик. Для личного APK система может показать дополнительное подтверждение неизвестного разработчика.

В 0.3.1 исправлено сохранение учебного барьера после разблокировки PIN. Проверены несколько выбранных приложений, возврат из недавних, шторка и защищённый экран блокировки. Проверки выполнены на эмуляторе; конкретный телефон требует отдельной проверки.

В 0.3: разделы настроек, крупный шрифт и горизонтальное видео; раздельная сложность навыков, повтор ошибок в новых контекстах, связанные учебные проверки; исправления сохранения, резервной копии и отмены подключения.

Канал: `https://raw.githubusercontent.com/Nikita15313/plavno-updates/main/update.json`.

Здесь только подписанные APK и сведения о выпуске. Учебная история, записи голоса, исходники приложения и ключ подписи не публикуются. Сторонние лицензии и уведомления входят в приложение. Оценка правильности фонем, ударения и интонации пока не реализована.
