# Плавно — обновления

Личное приложение для практики английского на Android 8 и новее.

[Скачать Плавно 0.3.0](https://raw.githubusercontent.com/Nikita15313/plavno-updates/main/plavno-0.3.0.apk)

Установите APK поверх прежней версии, не удаляя приложение. Начиная с 0.3.0: **Настройки → Обновить приложение → Проверить и обновить**. Android попросит подтвердить установку. Учебная история и настройки сохраняются.

В 0.3.0: удобные разделы настроек, работа с крупным шрифтом и видео в горизонтальном положении; отдельная сложность навыков, возврат ошибок в новых контекстах, связанные проверки; исправления сохранения, резервной копии и отмены подключения.

Канал: `https://raw.githubusercontent.com/Nikita15313/plavno-updates/main/update.json`.

Здесь только подписанные APK и сведения о выпуске. Учебная история, записи голоса, исходники и ключ подписи не публикуются. Сторонние лицензии и уведомления входят в приложение.
